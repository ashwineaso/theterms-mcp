# Decisions

## SDK version (2026-08-17)

This project targets the v1.x line of `@modelcontextprotocol/sdk`, specifically version **1.12.3** — the latest published 1.x release as of today. The v1.x line provides a stable, unified SDK package for building MCP servers, as opposed to the newer v2.x split architecture (`@modelcontextprotocol/server`, `@modelcontextprotocol/client`, `@modelcontextprotocol/core`).

Install command: `npm install @modelcontextprotocol/sdk@^1.12.3`
